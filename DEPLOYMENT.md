# Deployment Guide — Sergio Troche Portfolio

> Nota: esta guía cubre el flujo genérico "Laravel standalone". El despliegue real y vigente
> del ecosistema Kapitalya es Docker Compose / K8s — ver `README.md` § K8s / Despliegue y
> `CLAUDE.md` de este proyecto para namespace, puertos y el estado de migración del cluster.

## Quick Start (Local)

```bash
# 1. Install PHP dependencies
composer install

# 2. Copy environment file
cp .env.example .env

# 3. Generate app key
php artisan key:generate

# 4. Configure your .env (see section below)

# 5. Clear caches
php artisan config:clear
php artisan view:clear
php artisan route:clear

# 6. Serve locally
php artisan serve
# → http://localhost:8001   (Spanish)
# → http://localhost:8001/en (English)
```

> Generate one for "Mail" and use that as MAIL_PASSWORD.

## Nginx Configuration (recommended)

```nginx
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;
    root /var/www/serguicv/public;
    index index.php;

    # Redirect HTTP to HTTPS
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name yourdomain.com www.yourdomain.com;
    root /var/www/serguicv/public;
    index index.php;

    # SSL — use Let's Encrypt (certbot)
    ssl_certificate     /etc/letsencrypt/live/yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/yourdomain.com/privkey.pem;

    # Security headers
    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";
    add_header X-XSS-Protection "1; mode=block";
    add_header Referrer-Policy "strict-origin-when-cross-origin";

    # Static asset caching (1 year)
    location ~* \.(css|js|jpg|jpeg|png|gif|ico|woff|woff2|ttf|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
        fastcgi_index index.php;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

## Docker (real deploy path for this ecosystem)

```bash
# Build and run — host 9081 → container 80 (see docker-compose.yml)
docker compose up -d --build
# → http://localhost:9081

# Run migrations (not needed — portfolio uses no real DB; DB_CONNECTION=sqlite is a no-op placeholder)
```

See `docker-compose.yml` for full configuration, and `README.md` § K8s / Despliegue for the
Kapitalya-wide image build/import workflow (`docker save | ctr images import`, never `docker push`).

## GitHub Actions CI/CD

A workflow is already configured at `.github/workflows/ci.yml`.
To add auto-deploy, add these secrets to your GitHub repo:

- `DEPLOY_HOST` — your server IP
- `DEPLOY_USER` — SSH user
- `DEPLOY_KEY` — private SSH key
- `DEPLOY_PATH` — path on server (e.g. `/var/www/serguicv`)
